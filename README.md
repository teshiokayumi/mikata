
## 校務のミカタ | 生成AI議事録・ToDo自動整形アプリ

会議の「あとで書く」をゼロに。**校務のミカタ**は、日本の教職員が直面する膨大な事務作業を削減し、子どもと向き合う時間を生み出すために開発された、Google Gemini API活用の議事録・ToDo自動整形アプリです。

### 概要

日本の教育現場では、小学校教員の約6割以上が事務作業の多さを深刻なストレス要因として挙げています。特に職員会議や学年会の後に発生する「議事録の作成」や「ToDoの整理」は、多大なエネルギーを消耗する作業です。

『校務のミカタ』は、重厚で複雑な既存の校務支援システムとは異なり、先生の横でサッとメモを受け取り、一瞬で書類の形に整える「フロントの自動化ツール」として機能します。

### 主な機能と特徴
#### 1. 柔軟な入力形式（フロントの自動化）

指定されたフォーマットに正確に入力する必要はありません。

• チャット形式: LINEのように思いついた時に短い文で発言を送信。
• 音声文字起こしの活用: ボイスレコーダーアプリ（CLOVA Note等）の文字起こし結果をそのまま貼り付け可能。
• 自動保存機能: 入力中の内容はブラウザに一時保存されるため、不意の画面閉じによるデータ消失を防ぎます。

#### 2. AIによる構造化出力

入力された断片的な情報を、AI（Gemini）が文脈から読み解き、以下の形式で自動整形します。
• 議事要約: 背景・経緯、決定事項、継続検討事項を整理。
• ToDoリスト: 「誰が」「何を」「いつまでに」を明確化。分掌や担当者別に分類。
• 次回アジェンダ案: 会議の内容から次に議論すべき事項を提案。

#### 3. スムーズな連携

• ワンクリックコピー: 生成された内容はボタン一つでクリップボードにコピー可能。
• 外部貼付: コピーした内容は、Wordや学校指定の校務支援システムへそのまま貼り付けることができます。

#### 4. 快適なユーザーインターフェース

• 目に優しいデザイン: グリーンを基調とした、清潔感のあるUI。
• レスポンシブ設計: PCだけでなく、タブレット等でも利用可能なレイアウト。
• ローカル管理: APIキーや設定はブラウザのローカルストレージにのみ保存されます。

##### 既存システムとの比較

従来の校務支援システム……指定フォーマットへの正確な入力が必要、人間が要約し、項目ごとに打ち込む、サーバー構築や高額なライセンスが必要
校務のミカタ……入力の柔軟性、チャットや音声メモ等、自由な形式でOK、AIが文脈から重要事項とToDoを自動分類、index.htmlを開くだけですぐに利用可能

##### 連携

整形済みテキストをどこにでも貼れる

### セットアップ方法

本アプリは3つのシンプルなファイル（index.html, style.css, app.js）で構成されています。
1. フォルダ内の index.html をブラウザ（Chrome等）で開きます。
2. 画面右上の 「API設定」 ボタンをクリックします。
3. Google AI Studioで取得した Gemini APIキー を入力します。
4. 使用するモデル（Gemini 2.0 Flash 推奨）を選択し、保存します。
5. 左側のチャット画面に会議メモを入力し、「議事録を生成」 を押すと完了です。

### 安全に利用するためのガイドライン（校務ハック）

生成AIを安全に校務に導入するために、以下のルールを推奨しています。
• 個人情報は入力しない: 児童生徒の名前は「Aさん」や「出席番号1番」などの伏せ字に置き換えて入力してください。
• AIの回答を確認する: AIは稀に「もっともらしい嘘（ハルシネーション）」をつくことがあります。出力されたToDoの担当者などは、必ず目視で最終チェックを行ってください。
• 既存ルールとの共存: 本アプリは公式記録を「置き換える」ものではなく、下書きを「補完する」ものです。最終的な記録は必ず学校指定のシステムへ保存してください。

### 開発の想い

「先生が、先生にしかできない仕事に集中できる環境」を取り戻すこと。 
議事録作成に費やしていた30分を5分に短縮できれば、残りの25分を子どもたちのために使うことができます。
事務作業をAIに任せ、先生が「心」を使う仕事へ専念できるようサポートします。
